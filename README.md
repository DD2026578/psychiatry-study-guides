# 精神病学学习指南

基于《精神病学（第9版，2024）》教材整理的 26 章互动学习指南 + 精神科治疗药物手册 + 精神症状学补充页（纯静态 HTML，无外部网络依赖）。

- 在线阅读：<https://dd2026578.github.io/psychiatry-study-guides/>
- 从 `index.html` 总目录进入任意章节；每章底部可「上一章 / 目录 / 下一章」切换；总目录卡片标注教材页码
- 自测题点击作答即时判定并计分；速记卡支持点击或键盘（Tab + Enter）翻转；手机端自适应
- 全站检索：任意页面按 `Ctrl/⌘+K` 或点右下角检索按钮，可跨 29 页搜索症状、药物、诊断要点；正文按段索引（约 1340 段），结果摘要围绕命中词截取，可直接跳转到对应锚点
- 学习状态：阅读进度、自测成绩、速记卡翻阅、书签与浏览位置保存在本机浏览器；总目录显示「继续学习」
- 右下角可切换亮/暗主题（暗色覆盖 80+ 类组件，全站无浅底浅字）；学习面板提供上一章/下一章与知识联动

维护：内容更新后运行 `python tools/build_enhancements.py` 重新生成检索索引与增强层（幂等，可重复运行，三次构建字节一致）。

自检：`python tools/regress.py` 检查结构、链接、锚点、索引一致性与体积；`python tools/scan_dark.py` 扫描暗色模式下残留的浅底组件。

仅供个人学习参考。
